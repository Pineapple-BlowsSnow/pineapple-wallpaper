# 菠萝壁纸 · 项目介绍

## 简短介绍

菠萝壁纸（Pineapple Wallpaper）是一款开源的 macOS 照片与视频壁纸应用。把自己的影像加入本地图库，随时切换桌面与屏保。无需账号，素材不上传。

## 完整介绍

把喜欢的画面，留在 Mac 桌面。

菠萝壁纸由 Pineapple-Tech 菠萝吹雪发起，为想用自己的影像布置桌面的 Mac 用户而做。将 JPEG、PNG、HEIC、TIFF 照片，或 macOS 可播放的 MP4、MOV 视频加入同一个图库后，点击缩略图就能切换壁纸。照片静态显示，视频静音循环播放。屏幕保护程序可以跟随当前壁纸，也能单独选择照片或视频。

作者：Pineapple-Tech 菠萝吹雪。

图库支持缩略图、搜索、收藏、重命名和重复文件识别，也能适配多显示器。所有素材都保存在这台 Mac 上，不需要账号，不上传文件。项目代码采用 MIT 许可证开放，欢迎阅读、修改和贡献；Pineapple Tech 品牌图案按 [BRAND.md](../BRAND.md) 单独授权。

目前提供适用于 macOS 15+、可自行构建的开源初版，尚无经过 Apple 公证的公开安装包。源码、构建方法和已知限制见 [README.md](../README.md)。
