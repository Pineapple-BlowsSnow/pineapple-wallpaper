# 菠萝壁纸 · 项目介绍

## 简短介绍

菠萝壁纸（Pineapple Wallpaper）是一款开源、离线的 macOS 照片与视频壁纸应用。将喜欢的影像加入本地图库，一键切换桌面画面，并让屏幕保护程序使用同一份图库。无需账号，素材不上传。

## 完整介绍

让喜欢的画面，留在你的 Mac 桌面。

菠萝壁纸由 Pineapple Tech 发起，为想用自己的照片和视频布置桌面的用户而做。你可以把 JPEG、PNG、HEIC、TIFF 照片，或 macOS 可播放的 MP4、MOV 视频加入同一个图库。照片会静态显示，视频会静音循环播放；打开应用或菜单栏，就能随时切换。屏幕保护程序也能跟随当前壁纸，或者单独选一张照片、一段视频。

作者：Pineapple-Tech 菠萝吹雪。

图库支持缩略图、搜索、收藏、重命名和重复文件识别，也能适配多显示器。所有素材都保存在这台 Mac 上，不需要账号，不上传文件。项目代码采用 MIT 许可证开放，欢迎阅读、修改和贡献；Pineapple Tech 品牌图案按 [BRAND.md](../BRAND.md) 单独授权。

目前提供可自行构建的 macOS 初版，尚无经过 Apple 公证的公开安装包。构建和使用方法见 [README.md](../README.md)。
